## What's new

### Drive the studio from Claude Code, Codex or Claude Desktop
- **Settings → Claude & Codex**: connect an agent with one click. The studio runs a local MCP server and a REST API (68 tools), so the agent works with the same tools you have: script, world, cast and outfits, director, storyboard, generation, continuity review. Every change shows up live in the studio, and recent agent actions are listed in Settings.
- Long batches run as background jobs with progress and can be cancelled (`project_job_status`, `project_cancel_job`).
- The director is available to agents scene by scene, with the same coverage rules as the built-in director.

### Continuity that looks at the frames
- **Visual continuity review**: a vision model compares each frame with the shots before and after it *on screen*, the scene's establishing shot and the cast, outfit and location references — identity, wardrobe, props, lighting, the 180° rule, eyelines, postures across the cut, crowds, readable text, framing and render artifacts — and returns a concrete prompt fix.
- **Automatic reverse angles**: when a shot needs the other side of the room, the studio renders that view of the location (keeping its crowd) and re-renders the shot against it.
- Shots are ordered by scene and position, not by shot number, everywhere continuity is checked.

### Models and providers
- Nano Banana 2.1, Qwen Image 2.1 (FAL), FLUX.3 and Krea 3, MachGen (MiniMax H3 Turbo).
- Local AI workspace: local LLMs, one-click model downloads, Draw Things and local ComfyUI models in the Project Hub.
- Choose the model for outfits and garment pieces; storyboard shots send their matching concept references.

### Fixes
- Midjourney (Jeff): jobs are matched by their words, so prompts with punctuation attach their results; flag values no longer swallow commas.
- Crash recovery reopens the last auto-save instead of a blocking dialog that froze the studio.
- Agent prompt edits replace a stale continuity-refined prompt; long error messages wrap and clear when you switch projects.
