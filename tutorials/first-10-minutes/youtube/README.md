## Description

```text
Install a free, open-source AI film studio and set up your first project in under 4 minutes. AI Video Production Editor takes you from script to storyboard, from storyboard to AI-generated shots (Veo, Kling, Seedance), and on to the edit, color, sound and export – all in one project folder on your own machine, with your own API keys.

⬇️ Download (macOS / Windows): https://github.com/LudwigKienle/ai-video-production-editor/releases/latest
💻 Source code: https://github.com/LudwigKienle/ai-video-production-editor
📖 Written guide: https://github.com/LudwigKienle/ai-video-production-editor/blob/main/docs/FIRST_10_MINUTES.md

In this tutorial:
• Install the desktop app, or run it from source (Node 22+, npm run electron:dev)
• The welcome guide: Simple vs. filmmaker mode, theme, connecting an AI provider (Google Gemini has a free tier)
• A tour of the studio: workspaces, Simple / Standard / Pro modes, Activity and AI Tools
• Choosing a project folder so everything saves locally
• The Project Hub: pick a format, paste a script, Analyze Script
• The seven production steps: Script, World, Concept, Storyboard, Filming, Review, Marketing
• Standalone Images and Video generators, and Node Space
• Timeline (cut, color, sound) and Export presets for YouTube, TikTok and Instagram
```
